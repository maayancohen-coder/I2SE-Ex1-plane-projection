# Dataset

NRRD files are not committed (see `.gitignore`). Place them in this folder locally.

| File | Size (voxels) | Type | Spacing | Source | Why |
|------|---------------|------|---------|--------|-----|
| `MRHead.nrrd` | 256 x 256 x 130 | int16 (short) | 1, 1, 1.3 | 3D Slicer sample data | the reference file of the assignment |
| `biscuit_cake.nrrd` | 256 x 256 x 130 | uint16 | 1, 1, 1.3 | | unsigned 16-bit values |
| `onion.nrrd` | 256 x 256 x 130 | uint8 | 0.55, 0.55, 0.715 | | non-uniform spacing |
| `croissant.nrrd` | 500 x 500 x 500 | uint8 | 0.37 | | performance benchmark (500^3) |
| `phantom_knot.nrrd` | 200 x 200 x 200 | uint8 | 1 | generated by `make_phantom.py` | known geometry for tests |

Generate the phantom:

```
python data/make_phantom.py data/phantom_knot.nrrd 200
```
